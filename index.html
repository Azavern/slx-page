// CARA MAIN

Lima langkah dari nol sampai Legenda

Semua berjalan di dalam satu desktop virtual di HP kamu — tidak ada aplikasi lain yang perlu dibuka.

01

Login Google, buat akun

Login dengan akun Google, lalu buat username 3–16 karakter. Kamu otomatis dapat email @connection.mail, PC level 1, modal $500, dan IP virtual acak.

02

Ambil misi di MISSION

Pilih negara, provinsi, lalu targetnya. Setelah misi dimulai, adu cepat: selesaikan crack sebelum trace selesai dan posisimu terlacak.

03

Kumpulkan hasil misi

Misi berhasil memberi $ + DP + Reputasi + XP. Misi gagal menurunkan reputasi — dan kamu bisa kena hack-back dari target.

04

Belanja di STORE

Pakai hasil misimu untuk upgrade hardware dan software di STORE. PC yang lebih kuat membuka target yang lebih sulit dan hadiah yang lebih besar.

05

Mining BTC, naik level

Rig kamu menambang BTC untuk membiayai hardware tier atas. Setiap naik level memberi C-Coin dan membawamu lebih dekat ke gelar berikutnya.

// DESKTOP VIRTUAL

Satu desktop, 9 aplikasi

Seluruh permainan hidup di desktop virtual ini — dari membaca email sampai menambang BTC.

EMAIL

Kotak masuk in-game untuk email @connection.mail, info misi, dan pemberitahuan akun.

STORE

Toko untuk membeli upgrade hardware dan software serta item Premium.

MISSION

Papan misi — pilih negara, provinsi, dan target, lalu mulai crack.

TERMINAL

Baris perintah untuk menjalankan perintah langsung di PC virtualmu.

LEADERBOARD

Papan peringkat pemain berdasarkan level dan reputasi.

HARDWARE

Lihat dan kelola komponen PC virtualmu, dari CPU sampai rig mining.

SOFTWARE

Lihat dan kelola perangkat lunak yang terinstal di PC virtualmu.

GLOBAL

Chat global untuk ngobrol dengan pemain lain dari seluruh dunia.

MINING

Kelola rig penambang dan pantau hasil BTC yang masuk.

// EKONOMI DALAM GAME

Lima mata uang, satu ekosistem

Setiap sumber daya punya sumber dan kegunaannya sendiri — tidak ada yang bisa digantikan oleh yang lain.

$
Dolar

Dari misi, daily claim, dan level-up. Mata uang utama untuk belanja hardware dan software.

BTC
Bitcoin

Dari mining dan level-up. Dibutuhkan untuk komponen tier atas.

R
Reputasi

Naik dari misi yang berhasil, turun saat gagal. Menentukan posisimu di mata pemain lain.

DP
Data Points

Poin data hasil crack target, dikumpulkan dari setiap misi.

C
C-Coin

+1 tiap naik level. Dipakai khusus untuk membeli item Premium.

Top-up C-Coin belum tersedia. Satu-satunya cara mendapat C-Coin saat ini adalah naik level.

  • Ganti IP10 C-Coin

Harga campuran $ + BTC

Komponen tier atas tidak cukup dibayar dengan dolar saja. Contoh:

CPU tier 7 = $25.000 + BTC 0,12

// TENTANG GAME INI

Game indie kecil, tujuan edukatif

Dibuat oleh RFL-KSPULLX

CONNECTION adalah game indie kecil karya RFL-KSPULLX (Andika Saputra). Game ini merupakan remake dari Hackerz Online MMO Simulator, dengan mekanik yang diadaptasi dari proyek open-source Secret Republic.

Tujuannya edukatif: belajar konsep keamanan siber lewat permainan — bukan mengajarkan kejahatan nyata. Semua peretasan di dalam game adalah simulasi.

Jalan lokal, bisa offline

Game berjalan lokal di HP kamu dan bisa dimainkan offline. Server hanya menangani akun, leaderboard, sinkronisasi, chat, email, dan update.
